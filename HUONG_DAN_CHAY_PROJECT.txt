YÊU CẦU PHẦN MỀM

================================================================
  PHẦN 1: CÀI ĐẶT SQL SERVER (làm 1 lần duy nhất)
================================================================

BƯỚC 1 — Cố định port 1433 cho SQL Server
------------------------------------------
  1. Mở "SQL Server Configuration Manager"
     (Tìm trong Start Menu hoặc chạy: SQLServerManager16.msc)

  2. Vào: SQL Server Network Configuration
          → Protocols for MSSQLSERVER01

  3. Double-click "TCP/IP" → chọn tab "IP Addresses"

  4. Kéo xuống phần "IPAll":
     - TCP Dynamic Ports : XÓA TRẮNG (để trống)
     - TCP Port          : điền 1433

  5. Bấm OK

  6. Vào "SQL Server Services"
     → Chuột phải "SQL Server (MSSQLSERVER01)" → Restart


BƯỚC 2 — Bật SQL Server Authentication (Mixed Mode)
----------------------------------------------------
  1. Mở SSMS, kết nối vào: LAPTOP-FILDQM8N\MSSQLSERVER01
     (dùng Windows Authentication)

  2. Chuột phải vào tên server (trên cùng) → Properties

  3. Tab "Security" → chọn:
     "SQL Server and Windows Authentication mode"

  4. Bấm OK

  5. Restart SQL Server service (như Bước 1, mục 6)


BƯỚC 3 — Kiểm tra database trên SQL Server
----------------------------------
  1. Mở SSMS và kết nối vào SQL Server đang dùng cho project.

  2. Kiểm tra database "QL_ChuyenBay_DaNang" đã tồn tại
     trong Object Explorer.

  3. Nếu database chưa có, khôi phục/tạo database từ nguồn dữ liệu SQL Server
     của nhóm trước khi chạy backend.


BƯỚC 4 — Kiểm tra tài khoản SQL cho Backend
----------------------------------------
  Cấu hình hiện tại đang dùng tài khoản SQL Server:

    User     : sa
    Password : kin2112005

  Nếu máy bạn dùng tài khoản khác, cập nhật đồng thời:
    - Backend/db.js
    - Backend/src/main/resources/application.properties

  Nếu muốn dùng tài khoản riêng thay cho sa, trong SSMS có thể tạo login:

  USE master;
  CREATE LOGIN airport_user WITH PASSWORD = 'Airport@2026';

  USE QL_ChuyenBay_DaNang;
  CREATE USER airport_user FOR LOGIN airport_user;
  ALTER ROLE db_datareader ADD MEMBER airport_user;
  ALTER ROLE db_datawriter ADD MEMBER airport_user;
  GRANT EXECUTE TO airport_user;

  Sau đó đổi DB_USER/DB_PASSWORD cho Express và spring.datasource.username/password cho Spring Boot.


================================================================
  PHẦN 2: CHẠY PROJECT (mỗi lần làm việc)
================================================================

BƯỚC 5 — Cài dependencies (chỉ làm 1 lần sau khi clone)
---------------------------------------------------------
  Mở terminal (VS Code: Ctrl + `)

  Terminal 1 — Backend Express (Staff/Customer):
    cd Backend
    npm install

  Terminal 2 — Frontend:
    cd Frontend
    npm install


BƯỚC 6 — Khởi động Backend
----------------------------
  Hệ thống hiện dùng 2 backend:
    - Spring Boot port 8080: phục vụ cổng Admin
    - Express port 3001: phục vụ cổng Nhân viên và Khách hàng

  Terminal 1 — Spring Boot:

    cd Backend
    mvn spring-boot:run

  Kết quả thành công:
    Spring Boot chạy tại http://localhost:8080
    Health check: http://localhost:8080/api/health

  Terminal 2 — Express:

    cd Backend
    npm run dev

  Kết quả thành công:
    Express backend chạy tại http://localhost:3001
    Health check: http://localhost:3001/api/health

  ⚠ Giữ cả 2 terminal backend mở trong suốt quá trình làm việc


BƯỚC 7 — Khởi động Frontend
-----------------------------
  Mở terminal MỚI (không đóng 2 terminal Backend), chạy:

    cd Frontend
    npm run dev

  Kết quả thành công:
    VITE v6.x.x  ready in xxx ms
    ➜  Local:   http://localhost:5173/

  Mở trình duyệt vào: http://localhost:5173

================================================================
  PHẦN 4: CẤU HÌNH KẾT NỐI (nếu cần thay đổi)
================================================================

  File cấu hình Backend: Backend/db.js

  Thông tin kết nối hiện tại:
    Server   : localhost
    Port     : 1433
    Database : QL_ChuyenBay_DaNang
    User     : sa
    Password : kin2112005

  Backend Express có thể đổi cấu hình bằng biến môi trường:
    DB_SERVER, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD

  Backend Spring Boot đổi trong file:
    Backend/src/main/resources/application.properties

  Nếu chạy trên máy khác, thay "localhost" bằng IP của máy chạy SQL Server
  và đảm bảo port 1433 không bị firewall chặn.


================================================================
  XỬ LÝ LỖI THƯỜNG GẶP
================================================================

  Lỗi: "Failed to connect" hoặc "ETIMEOUT"
  → SQL Server chưa chạy hoặc port sai
  → Kiểm tra SQL Server Configuration Manager, đảm bảo
    TCP/IP đã bật và TCP Port = 1433
  → Restart SQL Server service

  Lỗi: "Login failed for user ''"
  → Chưa bật SQL Server Authentication (Mixed Mode)
  → Làm lại Bước 2

  Lỗi: "Login failed for user 'sa'"
  → Chưa tạo login hoặc sai mật khẩu
  → Kiểm tra lại mật khẩu trong Backend/db.js và application.properties,
    hoặc đặt biến môi trường DB_USER/DB_PASSWORD cho Express

  Lỗi: "Cannot open database QL_ChuyenBay_DaNang"
  → Database chưa tồn tại hoặc tài khoản SQL chưa được cấp quyền truy cập
  → Kiểm tra lại Bước 3 và Bước 4

  Lỗi Frontend: "localhost refused to connect"
  → Backend chưa chạy
  → Làm lại Bước 6
